# Optional visual assets

This source-only distribution omits deployment artwork and institutional logos.
The static directory is retained because the web application mounts it at startup.
Some logo images may be absent until the operator adds appropriately licensed
artwork or changes the image references in index.html and app.html.
Geometry construction and the assistant source do not depend on those logos.
Third-party artwork is not covered by the HeliCraft source-code license.
